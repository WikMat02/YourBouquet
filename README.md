# YourBouquet

YourBouquet is a full-stack web application for ordering flower bouquets.

Users can:

- browse ready-made bouquets,
- create custom bouquets,
- place orders without registration,
- create an account to manage order history,
- administrator can manage flowers, bouquets and orders.

## Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- NestJS
- Prisma
- PostgreSQL

### DevOps

- Docker
- Github Actions

### Testing

- Jest
- Playwright
