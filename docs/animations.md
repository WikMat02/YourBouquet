# Application Animations

## Landing Screen Animation

### Continue as Guest

When the user press the "Continue as Guest" button:

1. Decorative flowers slide outside the screen.
2. The button smoothly expands.
3. The entire screen transitions into the application.
4. The Home Page becomes visible.

---

## Sign In Transition

When the user presses "Sign In":

1. Fade-out animation starts.
2. User is redirected to the Login Page.
3. Login form fades into view.
