# Business Rules

## Guest

A guest can place an order without creating an account.

---

## Custom Bouquet

A customer can build a bouquet from available flowers.

The bouquet price is calculated automatically.

---

## Ready-made Bouquet

A bouquet contains predefined flowers.

Each bouquet has:

- name
- description
- price
- image
- flower list

---

## Orders

Each order must contain:

- at least one bouquet
- delivery address
- customer details

---

## User

A registered user can save multiple addresses.

---

## Administrator

Only administrators can edit bouquets and flowers.
