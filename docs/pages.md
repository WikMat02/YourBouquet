# Application Pages

## Landing Page

### Purpose

The landing page is the first screen displayed after opening the application.

Its purpose is to:

- introduce the application,
- allow the user to choose how they want to use the application,
- provide a visually attractive entry point.

---

### Components

- Application logo
- Application name
- Short slogan
- Decorative flower illustrations
- Continue as Guest button
- Sign In button

---

### Available Actions

#### Continue as Guest

The user enters the application without creating an account.

The application redirects the user to the Home Page after the transition animation.

---

### Sign In

The user is redirected to the Login Page.

After successful authentication:

- User -> Home Page
- Administrator -> Admin Dashboard

---

## Login Page

### Purpose

Allows registered users and administrators to authenticate.

### Components

- Email input
- Password input
- Sign In button
- Link to registration
- Forgot password (future)

---

## Home Page

### Purpose

Displays the main flower shop content.

### Components

- Navigation bar
- Featured bouquets
- Categories
- Search bar
- Promotions
- Footer

---

## Bouquet Details Page

Displays:

- bouquet image
- bouquet description
- flower description
- price
- Add to Cart button

---

## Custom Bouquet Builder

Allows customers to create their own bouquet.

Displays:

- available flowers
- flower quantity selector
- live price calculation
- bouquet preview
- Add to Cart button

---

## Cart Page

Displays:

- selected bouquets
- custom bouquets
- quantity controls
- total price
- checkout button

---

## Checkout Page

Displays:

- customer information
- delivery address
- payment summary
- order confirmation button

---

## Profile Page

Registered users can:

- edit profile
- manage addresses
- view order history

---

## Admin Dashboard

Administrator can manage:

- users
- flowers
- categories
- bouquets
- orders
