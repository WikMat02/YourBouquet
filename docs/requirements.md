# Functional Requirements

## Guest

- Browse bouquets
- Browse flowers
- Create custom bouquet
- Add products to cart
- Place order without registration

## User

- Login
- Register
- View profile
- View order history
- Repeat previous orders

## Administrator

- Add flowers
- Edit flowers
- Remove flowers
- Create bouquets
- Manage orders
- Manage accounts

## Non-functional

- Responsive design
- Authentication with JWT
- PostgreSQL database
- REST API
