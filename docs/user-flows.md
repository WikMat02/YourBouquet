# Guest Flow

1. Open homepage

2. Browse bouquets

3. Open bouquet details

4. Add bouquet to cart

5. Continue shopping

or

6. Create custom bouquet

7. Add to cart

8. Checkout

9. Enter delivery details

10. Complete payment

11. Receive order confirmation

# User Flow

1. Login

2. Browse bouquets

3. Create order

4. Checkout

5. View order history

6. Repeat previous order

# Administrator Flow

1. Login

2. Open admin dashboard

3. Manage users

4. Manage flowers

5. Manage bouquets

6. Manage categories

7. Manage orders
