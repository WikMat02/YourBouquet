# User Roles

## Guest

A guest can:

- browse bouquets
- browse flowers
- create a custom bouquet
- add bouquets to the cart
- place an order without registration
- track an order using the order number (future)

Limitations:

- cannot view order history
- cannot save favourite bouquets
- cannot manage profile

---

## User

A registered user can:

- log in
- edit profile
- change password
- save delivery addresses
- browse bouquets
- create custom bouquets
- place orders
- view order history
- repeat previous orders

---

## Administrator

An administrator can:

- manage users
- block and unblock user accounts
- change user roles
- manage flowers
- manage bouquet categories
- manage bouquets
- manage orders
- change order status
- manage application content
